💳 Mercado Pago / Pix

Configure o pagamento automático. O Access Token fica armazenado no banco e nunca é mostrado no navegador.

⚡ Mistic Pay / Pix

Segundo intermediador PIX, separado do Mercado Pago. Usa as credenciais oficiais da MisticPay (Client ID/Public Key + Client Secret/Secret Key). As chaves secretas ficam somente no banco/backend.

🌙 EclipsePay / Pix

Terceiro intermediador PIX. Usa a chave API da EclipsePay somente no servidor, via Authorization: Bearer.

Taxa fixa desta versão: R$ 0,50 por transação, sem porcentagem. Ex.: R$ 165,00 → cliente paga R$ 165,50.

Observação: outros gateways PIX podem usar API Key, mas cada empresa possui endpoints e formato de resposta próprios. Esta integração já fica isolada em um adaptador para permitir adicionar outros provedores depois sem mexer no Mercado Pago.
